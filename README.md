## AVAILABLE FOR FREE AT POLYTECLAB.COM

A vintage-character drum machine plugin built with [HISE](https://hise.audio), featuring 8 independently controllable drum channels with deep sample selection and analog-inspired master processing.

> **Note:** This repository does not include samples. It is intended as a portfolio/demo of the plugin architecture and scripting approach.

## Overview

A sample-based drum instrument combining precise sample control with analog warmth. Each channel offers a multi-dimensional sample matrix navigated by two knobs (Pitch and Decay), giving immediate access to a wide tonal palette without menus or preset browsing. Sample counts vary per instrument from 6×10 to 10×13.

## Instruments & MIDI Map

| Note | Instrument |
|------|------------|
| C2   | Kick       |
| C#2  | Snare      |
| D2   | Snare 2    |
| D#2  | Closed Hat |
| E2   | Open Hat   |
| F2   | Cymbal     |
| F#3  | Conga      |
| G3   | Clave      |

Closed and Open Hat share a single Sampler channel with hardware-style choke — triggering either hat stops the other.

## Features

### Per-Channel Controls
- **Pitch** — selects sample pitch variant
- **Decay** — selects decay variant per pitch
- **Fade In** — AHDSR-based attack control for shaping transients
- **Tune** — continuous fine-tuning in cents (selected channels)

### Conga
Additional synthesis layers on top of the sample:
- **Click** — short sine burst for attack transient definition
- **Noise** — filtered noise for body texture

### Mixer Panel
- Per-channel volume and pan
- Mute and Solo per channel

### Master Section
- **Drive** — tube-style saturation
- **Shape** — waveshaper (atan curve) for analog warmth and glue
- **Dust** — continuous vinyl noise with subtle crackle and breathing LFO modulation

## Technical Details

- Built with **HISE 4.1**
- Compiled with **Visual Studio 2022** (Windows) / **Xcode** (macOS)
- 48kHz / 24-bit sample engine
- Sample matrix varies per instrument (6×10 to 10×13)
- Hat choke implemented via HISE RR group system
- Scripted in HISE's JavaScript-based scripting engine
- Exports as VST3 / CLAP / AU

## Building from Source

### Requirements
- [HISE 4.1](https://github.com/christophhart/HISE) source code (tag `4.1.0`)
- Visual Studio 2022 Community (Windows) or Xcode (macOS)
- VST3 SDK (extract `tools/SDK/sdk.zip` in HISE source)

### Steps
1. Clone this repository
2. Open the project in HISE 4.1
3. Add your own samples to `Samples/` and generate soundmaps
4. Export from HISE to generate `Binaries/AutogeneratedProject.jucer`
5. Open `Binaries/Builds/VisualStudio2022/*.sln` in Visual Studio
6. Set configuration to **Release / x64**
7. Build Solution (`Ctrl+Shift+B`)
8. Find compiled plugin in `Binaries/Compiled/`
